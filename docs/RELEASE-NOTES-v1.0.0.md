The original ClickDesk release records mouse click positions, order, and timing, then replays the sequence.

For the current English desktop app, use the [latest release](https://github.com/caishoubin/clickdesk/releases/latest).

## Run the original version

Download **ClickDesk-Windows-x64.zip**, extract it, and run **ClickDesk.exe**. Supports Windows 10 / 11 x64 with the runtime included. The original v1.0.0 interface is in Simplified Chinese.

- F6 starts / finishes recording, F7 starts / stops playback, and F8 stops anytime.
- Supports left, right, and middle clicks, holds, double-click timing, repeat counts, speed settings, countdowns, local files, and a click test pad.
- Core tests and a Windows startup / shutdown check passed at publication. Actual desktop input still needs manual verification.

Keep the target window position and display settings unchanged. Compatibility with games is not verified; games may restrict automation or ignore simulated input. Check their rules before use.
