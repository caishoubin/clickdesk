ClickDesk · Windows Mouse Recorder
For Windows 10 / 11 x64

Extract the ZIP and run ClickDesk.exe. No Python or .NET installation is required.

1. Open the target application and position its window.
2. Press F6. Recording starts after the countdown (3 seconds by default).
3. Perform your sequence of clicks. Press F6 again to finish recording.
4. Set the repeat count. Keep the speed at 1.00 for the original timing.
5. Press F7 to replay. Press F8 anytime to stop.

Global shortcuts still work while the app is minimized. You can also stop
from the ClickDesk tray icon's right-click menu.

For a first try, select "Open click test pad". Record clicks on A, B, and C,
then replay to check the actual order, counts, and timing.

Supports left, right, and middle clicks, double-click timing, holds,
repeat counts, continuous loops, speed adjustment, a start countdown,
extra pauses between rounds, and local recording files.

Keep the target window, monitor layout, resolution, and scaling unchanged.
The wait before the first click and after the final click is kept in each round.
Actual timing depends on Windows scheduling and the target application.

Does not record keyboard input, scrolling, or continuous movement paths.
If the target app runs as administrator, ClickDesk needs the same permissions.
If F8 is already in use, close the other application and restart ClickDesk.

Recordings stay local. No recording upload feature or account is required.
Compatibility with games is not verified. Games may restrict automation or
ignore simulated input; check their rules before use.

The release workflow runs core tests and a Windows startup / shutdown check.
Actual mouse input still needs manual verification.
