ClickDesk · Windows 鼠标录制器
适用：Windows 10 / 11，x64 电脑

解压后直接双击 ClickDesk.exe，无需安装 Python 或 .NET。

1. 打开目标程序，将窗口放好。
2. 按 F6，默认倒计时 3 秒后开始录制。
3. 完成一次鼠标点击操作，再按 F6 结束录制。
4. 设置重复次数，速度保持 1.00，按 F7 开始回放。
5. 按 F8 随时停止。最小化后快捷键仍然有效。

第一次使用建议点击右侧“打开点击测试板”，录制 A → B → C，
然后回放，观察显示的点击次数、顺序和时间间隔。

支持左键、右键、中键和双击节奏；支持持续循环、速度调整、
每轮额外等待、倒计时，以及保存和打开录制文件。

请保持目标窗口位置、屏幕布局和缩放设置不变。
倒计时结束后到首次点击，以及最后一次点击到停止之间的等待
都会保留在每一轮回放中。Windows 调度可能带来少量计时偏差。

不记录键盘、滚轮或连续移动轨迹，不用于重现拖拽路径。
如目标程序以管理员身份运行，ClickDesk 也需要同等权限。

如 F8 被占用，请关闭占用快捷键的程序后重新启动 ClickDesk。
通知区域的 ClickDesk 图标右键菜单也可以停止操作。
