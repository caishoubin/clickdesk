# ClickDesk · Windows 鼠标录制器

录制鼠标点击的坐标、顺序和时间间隔，录制完成后按同样的节奏重复执行。中文界面，支持 Windows 10 / 11 的 x64 电脑。

[下载最新版本](https://github.com/caishoubin/clickdesk/releases/latest) · [查看构建状态](https://github.com/caishoubin/clickdesk/actions)

## 直接使用

1. 解压 `ClickDesk-Windows-x64.zip`，双击 `ClickDesk.exe`。程序自带运行时，不需要安装 Python 或 .NET。
2. 打开需要操作的程序，将窗口放到合适的位置。
3. 按 **F6**。默认倒计时 3 秒，ClickDesk 自动最小化，随后开始记录点击。
4. 在目标程序中完成一次操作，再按 **F6** 或 **F8** 结束录制。
5. 设置重复次数，保持速度为 **1.00**，按 **F7**。倒计时结束后开始按原节奏回放。
6. 任何时候按 **F8**，都可以停止倒计时、录制或回放。

建议首次使用时，点击右侧的“打开点击测试板”。按 F6 录制依次点击 A、B、C，再结束录制并回放，测试板会显示实际收到的顺序、次数和间隔。录制和回放期间请保持测试板位置不变。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| F6 | 开始 / 结束录制；也可取消录制倒计时 |
| F7 | 开始 / 停止回放；也可取消回放倒计时 |
| F8 | 全局紧急停止 |
| Esc | 主窗口获得焦点时停止当前操作 |
| Ctrl+S | 保存录制 |
| Ctrl+O | 打开录制 |

程序最小化后，全局 F6 / F7 / F8 仍然有效。也可以双击任务栏通知区域的 ClickDesk 图标恢复窗口，右键该图标选择“停止操作”。如果 F8 被其他程序占用，ClickDesk 会提示并阻止开始，关闭占用程序后重新启动即可。

## 回放设置

- **重复次数**：默认执行 1 轮。勾选“持续循环”可以一直重复，直到按 F7 / F8 停止。
- **回放速度**：1.00 倍是原速，2.00 倍将录制时间减半，0.50 倍将录制时间加倍。支持 0.10～10.00 倍。
- **每轮额外等待**：上一轮结束到下一轮开始之间的额外间隔，默认 1 秒。仅在两轮之间添加，不会改变单轮内部的点击间隔。
- **开始前倒计时**：录制和回放都适用，可设 1～10 秒。
- **开始时自动最小化**：为目标程序让出屏幕空间，结束后自动恢复主窗口。

## 时间与点击如何记录

- 记录左键、右键、中键的按下和松开，保留按住时长与双击节奏。
- 时间线的“间隔”指本次按下与上次按下之间的时间；第一行表示从录制开始到首次按下的等待时间。
- 倒计时不计入录制。倒计时结束后至首次点击的等待、最后一次点击至停止录制的等待都会保留，并在每一轮回放中重现。
- 按 F8 结束长按或回放时，会为录制或模拟按住的鼠标按键补上松开事件。
- 对主控制窗口的点击会被忽略。点击测试板是专门的操作目标，会正常记录。
- 采用单调时钟和绝对时间调度，避免每次等待造成累计误差。实际精度受 Windows 调度和目标程序响应速度影响，不保证硬实时或绝对毫秒精度。

## 保存与导入

点击“保存录制”将记录保存为 `.clickdesk.json`，下次点击“打开录制”即可重复执行。文件包含按键、屏幕坐标、事件时间和屏幕范围。只读取文件不会自动执行，仍需手动开始回放。

录制文件全部保存在本地，工具没有网络上传功能。清空、重新录制、打开其他文件或关闭程序前，如有未保存记录会提示保存。

## 使用范围

本工具按屏幕上的**绝对坐标**点击，请保持目标窗口位置、显示器排列、分辨率和缩放设置与录制时一致。支持带负坐标的多显示器桌面；若某个录制坐标已超出当前屏幕，会阻止回放。

本版记录点击，不记录键盘、滚轮或连续鼠标移动轨迹，因此不用于重现拖拽路径，也不提供识图或控件定位。回放时请让目标程序处于可见位置，并避免手动移动鼠标干扰。程序不主动切换目标窗口。

若目标程序以管理员身份运行，请用同样权限启动 ClickDesk。Windows 安全桌面、锁屏、登录界面，以及拒绝模拟输入的程序不在支持范围内。

《梦幻西游》尚未进行兼容性实测，不保证游戏接受模拟输入；使用前请确认游戏官方规则。

每次录制最长 24 小时，最多 100,000 个按下 / 松开事件。达到上限会自动停止并保留记录。

## 从源码构建

需要 .NET 10 SDK。Windows 上可以执行：

```powershell
dotnet run --project tests/ClickDesk.Core.Tests -c Release
dotnet run --project src/ClickDesk -c Release
```

运行 `build.ps1` 会先验证核心逻辑，再生成自带运行时的 Windows x64 单文件程序和 ZIP 包：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

也可手动发布（支持在 Linux 上交叉编译）：

```text
dotnet publish src/ClickDesk/ClickDesk.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o dist/ClickDesk-Windows-x64
```

输出：`dist/ClickDesk-Windows-x64/ClickDesk.exe`。运行时已包含在程序内，所以文件大小会大于依赖本机 .NET 的版本。

## 项目结构与验证

- `src/ClickDesk`：中文 WinForms 界面、全局鼠标钩子、SendInput、托盘和点击测试板。
- `src/ClickDesk.Core`：录制缓冲、文件校验和原子保存、坐标换算、可取消的回放调度。
- `tests/ClickDesk.Core.Tests`：无需额外测试框架的核心回归测试。
- `docs/WINDOWS-TESTING.md`：Windows 实机检查步骤。

GitHub Actions 会在 Windows 上执行 12 项核心回归测试、生成免安装程序，并检查程序启动、主窗口创建和正常退出。全局输入、实际点击命中和游戏兼容性仍需实机验证；首次使用可以先运行内置点击测试板。

在主分支提交会运行构建检查；推送与项目版本匹配的标签（例如 `v1.0.0`）后，会在检查通过后自动发布 Release，附带免安装包、源码包和 SHA-256 校验文件。也可在 Actions 页面手动运行构建。
