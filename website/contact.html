CONTACT & SUPPORT

A question?
Let’s take a look.

ClickDesk is maintained by caishoubin. The project’s support channel is GitHub Issues, where you can report bugs, ask about a feature, or suggest an improvement.

Get help with ClickDesk

When reporting a problem, include your Windows version, the ClickDesk version, what you expected, what happened, and the steps needed to reproduce it.

Open GitHub Issues

Start with a short test

Open the desktop app’s click test pad. Press F6, click A, B, and C after the countdown, then press F6 to finish. Press F7 to replay. Use F8 to stop anytime. Keep the test window’s position unchanged while checking the sequence and timing.

For detailed instructions, read the English user guide.

Downloads and source

The current Windows x64 portable package, source code, release notes, and SHA-256 checksums are available from the project’s GitHub release page. Extract the ZIP and run ClickDesk.exe.

For questions about website information or privacy, use the same support channel and identify the relevant page. See our Privacy & Cookies notice for the website’s current data handling.
