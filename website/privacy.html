This notice describes the ClickDesk product website and its links to the Windows desktop app. The website is maintained through the ClickDesk GitHub project.

The interactive demo

The homepage demo keeps click targets and timing in the page’s memory. It does not send your demo sequence to a server or save it to a recording account. Reloading or closing the page clears the custom sequence.

The website does not request access to your desktop mouse activity or your computer’s recording files. ClickDesk desktop recordings are stored locally in files you choose to save.

Hosting and technical information

This website is hosted with ChatGPT Sites. The hosting provider may process technical request information, such as IP addresses, browser information, access times, and operational logs, to deliver, secure, and maintain the website. Its processing is described in OpenAI’s Privacy Policy.

The website’s own code does not provide a sign-up form, analytics tracker, or recording upload service.

Advertising and cookies

Google advertising is not active in this version of the website. We have added publisher verification information for Google AdSense. This version does not load the AdSense ad-serving script or request ads.

If advertising is enabled in a later update, Google and other advertising vendors may use cookies, IP addresses, device identifiers, and similar technologies to serve and measure ads. Advertising cookies may allow Google and its partners to personalize ads using prior visits to this and other websites.

You can manage Google advertising preferences through My Ad Center. See how Google uses information from sites that use its services and Google’s Privacy Policy for more information.

Before advertising is activated, this notice and any required consent controls will be updated to reflect the advertising services and choices available to visitors.

GitHub downloads and support

Downloads, source code, release notes, and support discussions are hosted on GitHub. Following those links takes you to a separate service with its own privacy practices. Information you submit in a public GitHub issue is visible to other visitors.

See GitHub’s Privacy Statement.

Questions and updates

Contact the project maintainer through the links on our contact page. This notice will be updated when the website’s data handling changes.
