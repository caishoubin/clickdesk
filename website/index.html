Ask on GitHub
What do I need to run ClickDesk?+

A Windows 10 or Windows 11 computer with an x64 processor. Download the ZIP from GitHub, extract it, and run ClickDesk.exe. The runtime is included; you do not need to install Python or .NET.

Will it click in the same place every time?+

Yes. Playback uses absolute screen coordinates. Keep the target window, monitor arrangement, resolution, and display scaling the same as when you recorded. ClickDesk does not recognize on-screen content or automatically follow a moving window.

Can I use it with games?+

Compatibility with games is not verified. Some games may ignore simulated mouse input or restrict automation. Check the game’s rules before using it. ClickDesk does not recognize game states, navigate, or make gameplay decisions.

Does it record my keyboard or upload my data?+

The desktop tool records mouse clicks, not keyboard input, scrolling, or continuous movement paths. Recordings are saved locally. It has no recording upload feature or account requirement.

Is the desktop app in English?+

Yes. The website, desktop interface, settings, messages, and bundled quick-start guide are in English. Use F6 to record, F7 to replay, and F8 to stop anytime.

How can I try it before a real task?+

The desktop app includes a click test pad. Record a few clicks on its A, B, and C buttons, then replay them to check the sequence and timing before using another application.
